# 🧊 냉각 소재 비교 계산기

뜨거운 음료를 원하는 온도로 식히려면 얼음, 젤 아이스팩, 스테인리스 큐브(재사용 얼음), 위스키 스톤이 각각 얼마나 필요한지 열평형으로 계산해 비교합니다.

80°C 커피 300g을 10°C로 식히려면 얼음은 약 212g이면 되지만 스테인리스 큐브는 약 6,270g(얼음의 약 30배)이 필요합니다. 얼음은 녹을 때 잠열을 흡수하지만, 녹지 않는 소재는 현열만 흡수하기 때문입니다.

## 파일 하나, 실행 두 가지

`app.py` 한 파일이 콘솔 프로그램과 웹앱 두 가지로 실행됩니다. 계산 함수는 하나라서 두 화면의 결과가 항상 같습니다.

| 실행 방법 | 모습 |
|---|---|
| IDLE에서 F5 또는 `python app.py` | 까만 창에서 숫자를 입력하는 콘솔 프로그램. 마지막 물음에 `w`를 누르면 웹앱이 브라우저에 열림 |
| `streamlit run app.py` | 슬라이더·표·막대그래프가 있는 웹앱 |

`w`를 눌렀을 때 Streamlit이 설치돼 있으면 이 파일을 웹앱으로 직접 실행하고, 없으면 배포해 둔 주소(https://cooling-calculator.streamlit.app)를 브라우저로 엽니다.

웹앱으로 쓰려면: `pip install streamlit` 후 `streamlit run app.py`
