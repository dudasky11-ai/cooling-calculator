# 🧊 냉각 소재 비교 계산기

뜨거운 음료를 원하는 온도로 식히려면 얼음, 젤 아이스팩, 스테인리스 큐브(재사용 얼음), 위스키 스톤이 각각 얼마나 필요한지 열평형으로 계산해 비교하는 Streamlit 웹앱입니다.

80°C 커피 300g을 10°C로 식히려면 얼음은 약 212g이면 되지만 스테인리스 큐브는 약 6,270g(얼음의 약 30배)이 필요합니다. 얼음은 녹을 때 잠열을 흡수하지만, 녹지 않는 소재는 현열만 흡수하기 때문입니다.

- `app.py` — 웹앱 코드

실행: `pip install streamlit` 후 `streamlit run app.py`
